# 🕵️ CamSpy — GoGo Gadget Webcam Finder

Find publicly shared webcams from local businesses, traffic agencies, and public cam directories.

## 📱 Build via GitHub (No PC Needed)

### Step 1 — Create GitHub repo
1. Go to **github.com** on your phone
2. Tap **+** → **New repository** → name it `camspy` → **Create**
3. Tap **uploading an existing file** and upload ALL files keeping folder structure

### Step 2 — Build
1. Repo → **Actions** tab → **Build CamSpy APK**
2. Tap **Run workflow** → wait ~5-8 minutes

### Step 3 — Download APK
1. Click the completed ✅ workflow run
2. Scroll to **Artifacts** → tap **CamSpy-APK** → download zip
3. Unzip → get `app-debug.apk`

### Step 4 — Install
1. Settings → Security → enable **Install unknown apps** for your browser
2. Tap the APK → Install → Open 🕵️

## Features
- Search by City/State or ZIP
- Sources: Windy, EarthCam, Google, Bing, Traffic DOT
- Proxy: Locked-to-1 or Auto-rotate modes
- IP badge shows current public IP before every scan
- Per-request proxy rotation for stealth
- Export results to CSV/JSON
